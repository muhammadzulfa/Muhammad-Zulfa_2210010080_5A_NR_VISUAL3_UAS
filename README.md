# CRUD Kategori

## Dokumentasi
Proyek ini menggunakan PyQt5 untuk membangun antarmuka pengguna (UI) dan MySQL Connector sebagai penghubung antara Python dan database MySQL untuk mengelola data kategori.

## Tujuan Proyek
Proyek ini bertujuan untuk mengimplementasikan operasi CRUD (Create, Read, Update, Delete) pada data kategori menggunakan kombinasi PyQt5 untuk UI dan MySQL sebagai basis datanya.

## Fitur Utama
1. **Tambah Kategori**: Menambahkan data kategori baru ke dalam database.
2. **Lihat Daftar Kategori**: Menampilkan semua data kategori yang ada di database.
3. **Ubah Kategori**: Memperbarui data kategori yang sudah ada.
4. **Hapus Kategori**: Menghapus data kategori dari database.

## Teknologi yang Digunakan
- **PyQt5**: Digunakan untuk membangun antarmuka pengguna aplikasi.
- **MySQL Connector**: Digunakan untuk menghubungkan Python dengan database MySQL.
